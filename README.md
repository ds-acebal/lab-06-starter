# Lab 6: Maps

## Introduction

We are developing a mobile application for travellers, called _Places_, which displays various kinds of locations: monuments, restaurants, photos taken by other users, and so on. Apart from the usual features of this kind of app (which are not the focus of this lab), we now need to display these locations on a map. To do so, we will use the Google Maps API (package `google.maps`).

## What to do

You must make the necessary design changes to allow these elements to be added to the map, following the design principles discussed in class. After that, complete the `main` method so that the steps described in the comments work as expected.

## Optional extension

If you finish — or as an optional take-home exercise —, a possible follow-up is to design how to allow editing of the elements displayed on the map using a form. In the `forms` package, you will find a sample class called `Forms`, which shows how the `author` and `address` fields of a monument could be edited. Your goal is to generalise this so that any two fields of any element can be edited.

As before, this extension includes another `main` method in the same package, which you should update once your design is complete so that the commented steps work properly.
